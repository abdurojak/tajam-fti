# Cloud Deployment Implementation Plan

**Goal:** Menyiapkan TAJAM FTI untuk Netlify + Neon dan mendorong kode ke GitHub publik.
**Architecture:** Store SQLite lokal dipertahankan; store PostgreSQL dipilih melalui environment. API asinkron dengan pemeriksaan akses bersama. Login melindungi halaman dan endpoint. Migrasi eksplisit dan konfigurasi Netlify disertakan.
**Tech Stack:** Next.js, TypeScript, node-postgres, PostgreSQL, SQLite, Vitest.

- [x] Tulis tes integrasi `tests/postgres.test.ts` memakai PostgreSQL sementara; jalankan sebelum implementasi untuk memastikan store baru belum tersedia.
- [x] Pisahkan `src/lib/database.ts` sebagai pemilih store, tambah `src/lib/postgres-store.ts`, `db/001-content.sql`, `scripts/migrate-db.mjs`. Uji CRUD, rollback, deduplikasi paralel, tanggal, restart koneksi. Jalankan `npm test -- tests/postgres.test.ts` dengan URL database tes.
- [x] Ubah tiga route konten menjadi await pada seluruh operasi store. Lindungi API dan halaman lewat modul auth sesuai metode terpilih; tambah tes sesi/origin dan akses gagal.
- [x] Sesuaikan label mode lokal/cloud, login/logout, panduan aplikasi. Pertahankan semua fitur Excel/PDF/kalender.
- [x] Tambah `.env.example`, `netlify.toml`, konfigurasi CI dan README deployment. Jangan menjalankan migrasi saat build. Default cloud gagal tertutup jika kredensial belum diisi.
- [x] Jalankan `npm test`, `npm run typecheck`, `npm run build`, integrasi API, pemeriksaan HTTP halaman login serta browser mode lokal. Lakukan review akhir.
- [ ] Inisialisasi Git, periksa file terpilih untuk publikasi, commit. Buat repositori publik di akun pengguna dan push; verifikasi URL dan visibilitas. Jika autentikasi diperlukan, selesaikan pekerjaan lokal dahulu dan jelaskan langkah akses yang masih diperlukan.
